### Pricing Tiers
| Tier | Price | Target |
|------|-------|--------|
| Free | ₩0 | 일반 사용자 |
| Pro | ₩X/월 | 개별 전문가 |

### LTV 추정
1명 사용자가 평생 가져다주는 매출 = ARPU × 평균 사용 기간
ex) ₩10,000/월 × 24개월 = ₩240,000

### Fixed Costs
- 개발 인건비
- 마케팅
- 사무실/도구

### CAC 추정
- 신규 1명 획득 비용
- Channel별 다름

### Unit Economics
```
LTV: ₩240,000
CAC: ₩80,000
LTV/CAC: 3:1 ✅ (3:1 이상 건강)
Payback Period: 8개월 ✅ (12개월 이내 건강)
```

## 빈 칸 = 위험

각 칸이 비어있다면:
- Problem 비어있음 → 아무도 원하지 않는 제품 만들 위험
- Customer Segments 비어있음 → 누구에게 팔지 모름
- UVP 비어있음 → 메시지 모호 → 마케팅 실패
- Solution 비어있음 → 구현 불가
- Channels 비어있음 → 사용자에게 도달 못 함
- Revenue Streams 비어있음 → 비즈니스 아님
- Cost Structure 비어있음 → Unit economics 모름
- Key Metrics 비어있음 → 개선 못 함
- Unfair Advantage 비어있음 → 경쟁자에게 따라잡힘

**9 칸 모두 채워져야 Stage 2로 진행 가능**.
