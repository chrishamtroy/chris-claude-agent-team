# Discovery Questions Template

> Stage 1에서 사용자에게 물을 핑퐁 질문 세트. 3 그룹으로 나누어 진행.

---

## Group A: 본질 (3 questions)

### 1. One-liner
"[누구]를 위한 [무엇]을 [어떻게] 제공하는 [카테고리]" 형태로 한 문장 작성.

예시:
- "강남 직장인을 위한 30분 보장 도시락 배달 서비스"
- "초등학교 교사를 위한 출석/학부모 알림 자동화 SaaS"

### 2. 핵심 문제 + Why now?
- 어떤 문제를 해결하나요?
- 왜 지금인가요? (시장/기술/규제/행동 변화 중 하나)

### 3. 타겟 사용자 페르소나
- 누구를 위한 제품?
- 가능하면 1명의 구체적 인물 (이름, 나이, 직업, 행동)

→ 사용자에게 중간 요약 보여주고 OK 받기

---

## Group B: 솔루션 (3 questions)

### 4. 달성 목표 (측정 가능)
- 출시 후 3개월/6개월/1년 어떤 결과가 성공인가?
- 예: WAU 1,000명 / 재주문율 40% / NPS 50

### 5. 핵심 기능 3~5개
- MVP에 반드시 들어갈 기능
- 우선순위 결정 (RICE는 Stage 2에서)

### 6. 차별점 (Unfair Advantage)
- 경쟁자가 쉽게 복사 못하는 것
- 시간/데이터/네트워크/규제 진입장벽 중 하나

→ 중간 요약

---

## Group C: 실행 (4 questions)

### 7. 플랫폼
- Web / Mobile (iOS/Android) / Desktop / 멀티
- B2C / B2B / B2B2C

### 8. 출시 수준
- MVP (가설 검증용) / Beta (제한적 공개) / GA (정식 출시)
- 출시 목표 시점

### 9. 비즈니스 모델
- Subscription / Transaction / Marketplace / Ad / Freemium
- 가격대 (대략)

### 10. 핵심 리스크
- 가장 큰 위험 3가지
- 시장/제품/실행/외부 중 어디?

→ 종합 요약 + `01-discovery.md`로 정리

---

## 사용자가 답하기 어려워할 때

### "잘 모르겠어요"
→ "가설로 답해 주세요. 가설 자체가 검증 대상입니다."

### "다 중요해요"
→ "만약 출시일이 1주일 앞당겨진다면 무엇을 빼시겠어요?"

### "경쟁사 없어요"
→ "사용자가 지금 이 문제를 어떻게 해결하고 있나요? 그게 경쟁자입니다."

### "기술이 작동하면 되죠"
→ "그것 자체가 가설입니다. 기술 가설 분리해 적어보죠."

## 객관식 옵션 활용

추상적 질문보다 옵션 제시:

```
"비즈니스 모델은?"
1. Subscription (월/연 정기 결제)
2. Transaction (건당 수수료)
3. Marketplace (양면 시장 수수료)
4. Freemium (무료 + 유료 기능)
5. 광고
6. 기타
```

사용자가 모호한 답 시 옵션 제시.
