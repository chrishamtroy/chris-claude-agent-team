# 한국 시장 출시 가이드

> 한국 시장에 SaaS/앱을 출시할 때 필수 고려사항.
> 글로벌 출시와는 다른 규제, 결제, 인증, 채널.

---

## 1. 한국 특수 규제

### 개인정보보호법 (PIPA)

#### 핵심 요구사항
- 수집 시 **동의 필수** (옵트인)
- 수집 목적 명시
- 보관 기간 명시 (목적 달성 후 즉시 파기)
- 제3자 제공 시 별도 동의
- 14세 미만 → 법정대리인 동의

#### vs GDPR 차이
- GDPR보다 더 엄격한 부분: 사전 동의 명확성
- GDPR보다 덜 엄격한 부분: DPO 의무 없음 (일부)

#### 실무 체크리스트
- [ ] 개인정보처리방침 페이지
- [ ] 수집 동의 UI (체크박스, 사전 체크 X)
- [ ] 수집 항목 명시 (이메일, 이름, 생년월일 등)
- [ ] 보관 기간 명시 (예: 회원 탈퇴 시까지)
- [ ] 파기 절차 명시
- [ ] 안전성 확보조치 (암호화 등)

### 정보통신망법

- 14세 미만 가입 제한
- 본인확인 의무 (게시판 등)
- 광고성 정보 발송 시 명시 ("(광고)" prefix)
- 야간 광고 발송 제한 (21~08시)

### 전자상거래법

- 청약 철회권 (7일)
- 통신판매업 신고 필수
- 결제 안내 의무
- 표시 의무 (사업자 정보, 약관 등)

### 표시광고법

- 부당한 표시·광고 금지
- "최고", "1위" 같은 표현 → 근거 명시 필수
- 비교 광고 → 정확한 근거

### 전자금융거래법 (결제 관련)

- PG사 계약 필수 (직접 결제 불가)
- 정기결제 → 사용자 동의 명확히

### 클라우드 컴퓨팅법 (공공/금융 SaaS)

- 공공기관: CSAP 인증 필요
- 금융: 금융보안원 인증

### 마이데이터 (2022~)

금융, 의료 분야에서 사용자 데이터 이동권 제도화.

## 2. 한국 결제 인프라

### PG (Payment Gateway) 선택

| PG | 강점 | 약점 | 수수료 |
|----|-----|-----|------|
| **토스페이먼츠** | 개발자 친화, 빠른 통합 | 비교적 신규 | ~3.3% |
| **카카오페이** | 카카오톡 알림, 사용자 친숙 | 카카오 의존 | ~3.3% |
| **네이버페이** | 네이버 사용자 풀 | UX 일관성 부족 | ~3.3% |
| **NICE페이먼츠** | 큰 가맹점 풀 | 통합 복잡 | 협상 |
| **KG이니시스** | 안정성, 대규모 | UI 구식 | 협상 |
| **PortOne (구 아임포트)** | 멀티-PG 통합 (위 다 지원) | 추가 fee | ~0.3% |

### 정기결제 (Subscription)

- **빌링키 기반** (카드 정보 토큰화)
- 토스/카카오/네이버 모두 지원
- 자동결제 실패 처리 (3회 재시도 후 해지 등)

### 결제 수단 다양화

한국 사용자는 결제 수단 선택권 중요:
- 신용/체크카드
- 카카오페이 / 네이버페이 / 토스
- 휴대폰 결제 (다날, KG모빌리언스)
- 가상계좌 (B2B 흔함)
- 무통장 입금

### 부가세

- 면세 vs 과세 사업
- B2B: 세금계산서 발행 의무
- B2C: 현금영수증 발행 가능

## 4. 알림 채널

### 카카오 알림톡

**왜 중요?**
- 한국 SMS 대비 비용 1/3
- 카카오톡 도달율 90%+
- 사용자가 카카오톡 안 보는 일 적음

**제약**:
- 광고성 메시지 금지 (정보성만)
- 사전 카테고리 승인 필요
- 발송업체 (Solapi, 비즈톡 등) 통해 발송

**활용 예시 (NewGen)**:
- 출석 안내
- 주일학교 행사 공지
- 학부모 안내

### SMS / LMS / MMS
- 광고는 SMS 가능
- 야간 발송 금지 (21~08)
- 수신 거부 표시 의무

### 푸시 알림
- 앱 푸시는 사전 동의 필요
- iOS: 시스템 권한
- Android: API 33+ POST_NOTIFICATIONS 권한

## 5. 한국 사용자 행동 특성

### 모바일 중심
- 데스크톱 < 모바일 (특히 2030)
- iOS vs Android 비율 약 30:70 (한국)
- 모바일 최적화 우선

### 채널 사용
- 카카오톡 = 모든 메시징의 중심
- 네이버 검색 (Google 대비 점유율 높음)
- 유튜브 (Z세대 검색까지)
- 인스타그램 / 틱톡 (2030)
- 페이스북 → 감소 추세

### 결제 행동
- 카드 사용 비율 매우 높음 (현금 < 카드)
- 페이먼츠 앱 사용 증가 (토스, 카카오)
- 신뢰 기반 (큰 회사 선호)

### 후기/리뷰 중시
- "인스타에서 봤어요"
- 블로그 리뷰 (네이버)
- 유튜브 리뷰
- 커뮤니티 (디시, 클리앙, 더쿠)

### B2B 특수성
- 종이 문서, 도장 문화 여전
- 세금계산서 발행 필수
- 대기업: 직접 영업 + 제안서 + PoC

## 7. 한국 SaaS 시장 특수성

### 시장 규모
- 한국 SaaS 시장 약 2~3조원 (2024 기준)
- 글로벌 대비 작지만 빠른 성장

### 가격 민감도
- 글로벌 가격 그대로 적용 시 비쌈
- 한국 시장 별도 가격 책정 권장
- B2B: 연 단위 결제 + 협상 가능

### 인지도
- 글로벌 도구 (Notion, Slack, Figma) → 인지도 높음
- 국산 도구 → 한글 + 카톡 연동 강점
- 외국 도구 한국 진입 시 → 한글화 + CS 한국어

### 경쟁
- 슬랙 ↔ 잔디 (네이버)
- 노션 ↔ 플로우 / 클로바노트
- 줌 ↔ 라인웍스 / 카카오워크
- 글로벌 도구가 점차 한글 지원

## 8. 한국 vs 글로벌 동시 출시

### 우선순위 결정

**한국 먼저** 가는 게 나은 경우:
- 한국 시장 특화 (예: 한국 교육 시스템)
- 한국어 NLP 필요
- 한국 결제/인증 의존도 큼
- 한국 네트워크 (학연/지연) 기반

**글로벌 먼저** 가는 게 나은 경우:
- 한국 시장 너무 작음 (B2B niche 등)
- 영어로 서비스 가능
- 글로벌 자본 유치 목표

### 동시 출시 시 trade-off

```
한국 + 영어 동시 = 2배 작업
한국 먼저 + 글로벌 나중 = 학습 후 확장
글로벌 먼저 + 한국 나중 = 한국 사용자 놓침
```

### 한국 + 글로벌 출시 시 체크

- [ ] i18n 구조 (한국어 + 영어)
- [ ] 결제: Stripe (글로벌) + 토스/카카오 (한국)
- [ ] 인증: 이메일 (글로벌) + 카카오/네이버 (한국)
- [ ] CS: 시간대 / 언어
- [ ] 법무: GDPR + 개인정보보호법 모두 준수
- [ ] 데이터 위치 (한국 사용자 데이터 한국 서버)

## 10. 한국 시장 안티패턴

❌ 글로벌 가격 그대로 적용 → 비싸다고 인식
❌ 영어 UI만 제공 → 사용자 이탈
❌ 카카오 알림 없이 SMS만 → 비용 ↑ 도달율 ↓
❌ Stripe만 지원 → 한국 사용자 결제 어려움
❌ 한국어 CS 없음 → B2B 신뢰 ↓
❌ 개인정보 약관 영문 → 법적 문제
❌ 14세 미만 처리 안 함 → 법규 위반
❌ "글로벌 표준" 고집 → 한국 특수성 무시
