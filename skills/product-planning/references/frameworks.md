## 1. Lean Canvas (Ash Maurya)

**창시자**: Ash Maurya (Running Lean 저자)
**기반**: Alexander Osterwalder의 BMC를 startup에 맞게 변형

### 9개 칸 구조

```
┌────────────┬──────────┬─────────────┬──────────┬────────┐
│ Problem    │ Solution │ Unique      │ Unfair   │Customer│
│            │          │ Value Prop  │ Advantage│Segments│
│ 1.         │ 1.       │             │          │        │
│ 2.         │ 2.       │ [한 줄]      │ [복제    │ Early  │
│ 3.         │ 3.       │             │ 불가]    │Adopters│
│            │──────────│             │──────────│        │
│ Existing   │ Key      │ High-level  │ Channels │        │
│ Alt.       │ Metrics  │ Concept     │          │        │
│            │ 1.       │ [메타포]     │ 1.       │        │
│            │ 2.       │             │ 2.       │        │
├────────────┴──────────┴─────────────┴──────────┴────────┤
│ Cost Structure         │ Revenue Streams                │
│                        │                                │
└────────────────────────┴────────────────────────────────┘
```

### 칸별 작성 가이드

#### 1. Problem (가장 먼저 채울 것)
- Top 3 problems
- Existing Alternatives: 현재 사용자가 어떻게 해결하고 있나?

#### 2. Customer Segments
- 일반 사용자 vs Early Adopters 구분
- Early Adopters만으로도 분기당 매출 가능한가?

#### 3. Unique Value Proposition
- 한 문장으로 "왜 우리?"
- High-level concept (메타포): "X for Y" 형식 (예: "Netflix for podcasts")

#### 4. Solution
- Problem 1~3을 각각 어떻게 해결?
- 최소 기능 (MVP)

#### 5. Channels
- Inbound vs Outbound
- Free vs Paid
- Direct vs Indirect

#### 6. Revenue Streams
- Subscription / Transaction / Marketplace / Ads
- Pricing model

#### 7. Cost Structure
- Customer acquisition cost
- Distribution cost
- People, hosting, etc.

#### 8. Key Metrics
- 5개 미만, 가장 중요한 것
- AARRR 각 단계마다 1~2개

#### 9. Unfair Advantage
- 쉽게 복사 불가능한 것
- 시간 들여야만 만들 수 있는 것

### Lean Canvas vs BMC 차이

| BMC | Lean Canvas | Why 다름 |
|-----|------------|---------|
| Key Activities | Solution | Startup은 활동보다 솔루션 |
| Key Resources | Key Metrics | 리소스보다 측정 중요 |
| Key Partners | Unfair Advantage | 파트너보다 차별점 |
| Customer Relationships | Channels | Channel에 포함 |

Lean Canvas는 "조직"보다 "제품 검증"에 적합.

## 3. Porter's Five Forces (Michael Porter, 1979)

### 5가지 힘

```
              [Threat of New Entrants]
                        ↓
[Supplier Power] → [Industry Rivalry] ← [Buyer Power]
                        ↑
              [Threat of Substitutes]
```

### 각 힘 분석 질문

#### 1. Threat of New Entrants (신규 진입 위협)
- 진입 장벽이 얼마나 높은가?
- 자본 요구사항?
- 규제?
- 브랜드 충성도?
- Network effects?

**낮은 위협 = 좋음** (우리에게)

#### 2. Bargaining Power of Suppliers (공급자 협상력)
- 공급자가 몇 명?
- 우리가 그들에게 큰 고객?
- Switching cost?

#### 3. Bargaining Power of Buyers (구매자 협상력)
- 구매자가 다른 옵션 있는가?
- 가격 민감도?
- 우리 제품이 그들에게 핵심? 부수?

#### 4. Threat of Substitutes (대체재 위협)
- 같은 Job을 다른 방법으로 해결 가능한가?
- 예: 자동차 → 자전거, 대중교통, 원격근무

#### 5. Industry Rivalry (기존 경쟁자 강도)
- 경쟁자 수?
- 시장 성장률 (낮을수록 치열)?
- 차별화 가능성?
- Exit barrier?

### 활용

각 힘이 약할수록 산업 매력도 높음.
→ 5가지 모두 약한 산업 진입 = 좋은 기회

## 4. Blue Ocean Strategy (Kim & Mauborgne)

### 핵심 개념

- **Red Ocean**: 기존 시장, 정의된 경쟁
- **Blue Ocean**: 새로 창조된 미경쟁 시장

### 전략 캔버스

```
가치
  ↑
  │  ╱─────────╲   Industry Standard
  │ ╱           ╲  ────────────────
  │╱  Our Curve  ╲ ─ ─ ─ ─ ─ ─ ─ ─
  └─────────────────────────────────→ Factors
     A  B  C  D  E  F  G
```

### Four Actions Framework

기존 산업에서 4가지 행동:

```
Eliminate (제거)     |  Raise (상승)
어떤 요소 없앨까?     |  어떤 요소 더 강화할까?
─────────────────────┼─────────────────────
Reduce (축소)         |  Create (창조)
어떤 요소 축소할까?    |  새 요소 무엇 추가할까?
```

### 예시: Cirque du Soleil

기존 서커스:
- 동물 공연 ❌ (Eliminate)
- 스타 곡예사 ❌ (Eliminate)
- 다중 무대 → 단일 무대 (Reduce)
- 텐트 분위기 ↑ (Raise)
- 음악/스토리텔링 추가 (Create)

결과: 서커스 + 연극의 새 시장 창조.

### Startup 적용
- 기존 카테고리에서 경쟁 ❌
- 새 카테고리 정의로 경쟁 회피
- 예: Notion (문서 + 위키 + 데이터베이스 통합)
- 예: Linear (이슈 트래커지만 속도/UX로 새 카테고리)

## 5. SWOT Analysis

```
        Internal               External
      ────────────           ────────────
Helpful │ Strengths   │  Opportunities
        │             │
Harmful │ Weaknesses  │  Threats
```

### 활용
- 빠른 전략 점검
- 외부/내부 균형
- 단점 → 보완 / 위협 → 회피

### 안티패턴
- 너무 일반적 ("좋은 팀")
- 액션 없이 끝남 → SWOT은 시작, 결정은 그 후

## 6. Marketing 4P (or 7P)

### 4P (전통적)

| P | What | Question |
|---|------|---------|
| **Product** | 제품 자체 | 무엇? |
| **Price** | 가격 | 얼마? |
| **Place** | 유통 채널 | 어디서? |
| **Promotion** | 홍보 | 어떻게 알림? |

### 7P (Services 추가)

+ **People**: 누가 (서비스 제공자)
+ **Process**: 어떻게 (서비스 프로세스)
+ **Physical Evidence**: 신뢰 증거

### SaaS 적용

- Product: 기능, UX
- Price: Subscription tier
- Place: Web, App Store, B2B sales
- Promotion: SEO, Content, Ads, Community

## 7. Crossing the Chasm (Geoffrey Moore)

### Technology Adoption Lifecycle

```
Innovators (2.5%) → Early Adopters (13.5%) → CHASM → Early Majority (34%) → Late Majority (34%) → Laggards (16%)
```

### 핵심 인사이트

- Early Adopters와 Early Majority 사이에 **chasm (틈)** 존재
- Early Adopters: 기술/혁신 자체에 끌림
- Early Majority: 검증/안정성/ROI를 원함
- 다른 마케팅 메시지 필요

### 적용

- 초기: 기능 강조, 비전 어필
- Chasm 건너기: 사례, 통합, 안정성 강조
- Beachhead 전략: 작은 시장 100% 점유 → 옆 시장 확장

## 8. Wardley Mapping (Simon Wardley)

전략 시각화 도구. Value Chain × Evolution 매핑.

```
Visibility ↑ (Visible to user)
  Customer Need
       │
  Genesis ─→ Custom-built ─→ Product ─→ Commodity
       Evolution → (시간/시장 성숙)
```

각 구성요소가 evolution 어디에 위치?
- Genesis: 신기술
- Custom-built: 우리만의 구현
- Product: 표준 제품
- Commodity: 흔한 서비스

**원칙**: Commodity는 build 말고 buy. Genesis는 직접.

## 9. STP (Segmentation, Targeting, Positioning)

### 단계

1. **Segmentation**: 시장을 비슷한 사람들 그룹으로 나누기
2. **Targeting**: 어떤 segment를 노릴지 선택
3. **Positioning**: 그 segment의 마음 속에 어떤 자리?

### Segmentation 기준

- 데모그래픽 (나이, 성별, 수입)
- 지리적
- 행동 (사용 빈도, 충성도)
- 심리적 (가치관, 라이프스타일)
- **JTBD 기반** (가장 강력) — 같은 Job 가진 사람들

### Positioning

**Positioning Statement Format**:
> For [target customer]
> who [statement of need or opportunity],
> our [product name] is a [product category]
> that [statement of key benefit].
> Unlike [primary competitive alternative],
> our product [statement of primary differentiation].

## 10. Disruptive Innovation (Clayton Christensen)

### 핵심 인사이트

신규 진입자가 기존 강자를 무너뜨리는 패턴:

1. 기존 강자가 무시하는 **low-end 시장**에서 시작
2. 또는 **non-consumption** 시장 (기존엔 서비스 안 받던 사람들)
3. 점진적 개선
4. 위로 올라가 mainstream 흡수

### 예시

- Netflix vs Blockbuster: 우편 DVD → 스트리밍 → 콘텐츠 제작
- Toyota vs GM/Ford: 저가차 → 중급 → Lexus
- Salesforce vs Siebel: SMB SaaS → Enterprise

### PM 적용

- 강자가 무시하는 영역에서 시작
- 처음엔 기능 적어도 OK (가격/접근성으로 승부)
- 시간 들여 위로 올라감
